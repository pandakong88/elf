FOLDER LAGU PET RADIO ELF (HINDIA PLAYLIST)
==============================================
Silakan salin file MP3 lagu Hindia ke folder ini dengan format nama berikut:

1. Lagu 1: Hindia - Everything You Are
   Nama file: hindia-everything-you-are.mp3 (atau everything-you-are.mp3)

2. Lagu 2: Hindia - Evaluasi
   Nama file: hindia-evaluasi.mp3 (atau evaluasi.mp3)

3. Lagu 3: Hindia - Berdansalah, Karir Ini Tak Ada Artinya
   Nama file: hindia-karir-ini-tak-ada-artinya.mp3
   (Bisa juga: hindia-berdansalah-karir-ini-tak-ada-artinya.mp3 / hindia-karir-ini-ga-ada-artinya.mp3)

Radio di kamar Sahabat ELF akan otomatis memutar ketiga lagu ini secara berurutan, lengkap dengan:
- Judul lagu & nama artis di layar radio
- Animasi pet berjoget
- Tombol [⏭️] untuk ganti lagu seketika
- Otomatis lanjut ke lagu berikutnya saat satu lagu selesai (auto-advance)
- Fallback ke melodi lofi santai jika file MP3 belum dimasukkan
